Full map – HMI, OB33, OB1, every block, and the path mode

The rectangle or the circle as one program run: the PLC writes up to seven poses into POSE 1 to 7 of the robot and one start drives them. This page shows the HMI with the tag on every object, OB33 and OB1 network by network with their pins, every DB, FB, FC and UDT, and how the data flows. The single-move way stays, a switch picks.

3. OB33 – the bus, four networks every 10 ms

Your cyclic interrupt. The files call it OB30, the content is the same. The stop pin takes the engine's program stop (engine v0.5), and the tags on the pose pins of network 2 change for the path mode.

NW1 · handshakeyours
toggle "DB_App".HS when the robot echoed it
writes "DB_App".HS, .HS_Stall, .HS_Alive, .HS_Count
the one writer of HS. HS_Alive goes into the status map as comm ok
NW2 · module 1, slot 18, hw 278pins change
